# Tic Tac Toe AI using Minimax Algorithm

## Overview

This project is an AI-powered Tic Tac Toe game developed in C++. The AI opponent uses the Minimax Algorithm with Alpha-Beta Pruning to make optimal decisions, ensuring highly competitive gameplay.

The project demonstrates core Artificial Intelligence concepts including game tree exploration, adversarial search, and optimization techniques.

---

## Algorithms Used

### Minimax Algorithm

The AI evaluates all possible future game states and selects the move that maximizes its chances of winning while minimizing the opponent's chances.

### Alpha-Beta Pruning

Optimization technique used to reduce the number of nodes explored in the game tree, significantly improving execution efficiency.
